# ✦ Projeto Redes Sociais

Projeto de estudo desenvolvido com **HTML5 e CSS3**, com foco na criação de uma interface que **simula a tela de um smartphone**, permitindo a navegação entre páginas internas por meio de botões laterais.

## 🔗 Demonstração

⌁ Acesse o projeto online:  
[https://mariapaulalopes.github.io/projeto-redes-sociais/](https://maria-paula-lopes-dev.github.io/projeto-redes-sociais/)

## ✧ Sobre o projeto

O **Projeto Redes Sociais** tem como objetivo simular a experiência de uso de um celular, utilizando apenas **HTML e CSS**, sem o uso de JavaScript.

A navegação entre as páginas é feita por meio de **botões laterais**, que alteram o conteúdo exibido dentro de um **iframe**, sem recarregar a página.

### ◈ Principais objetivos

▸ Simular a tela de um celular utilizando **imagem de fundo**  

▸ Utilizar **iframe** para troca de conteúdo interno  

▸ Criar botões de navegação lateral (Home, Instagram e GitHub)  

▸ Trabalhar posicionamento e alinhamento de elementos com CSS  

## ✧ Conceitos aplicados

▸ Uso de **iframe** para navegação interna  

▸ Posicionamento absoluto e relativo  

▸ Centralização de eleme
